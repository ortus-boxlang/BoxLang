### Print a line

```java
println( "Hello, World!" )
```

Result: Hello, World! followed by a line break

### Print several values

Each argument is printed on its own line.

```java
println( "first", "second" )
```

Result: first and second, each on its own line

### Print structured values

Complex values are converted to their string representation.

```java
println( [ 1, 2, 3 ] )
```

Result: the string representation of the array
