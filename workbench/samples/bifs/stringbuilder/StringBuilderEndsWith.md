### Check suffix with endsWith()

Tests whether a StringBuilder ends with a given substring.

```java
sb = sb{'Hello BoxLang'};
result = endsWith( sb, 'Lang' );
writeOutput( result );
```

Result: true

### Member usage

```java
sb = sb{'Hello BoxLang'};
result = sb.endsWith( 'Box' );
writeOutput( result );
```

Result: false
