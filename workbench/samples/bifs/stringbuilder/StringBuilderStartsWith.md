### Check prefix with startsWith()

Tests whether a StringBuilder starts with a given substring.

```java
sb = sb'Hello BoxLang';
result = startsWith( sb, 'Hello' );
writeOutput( result );
```

Result: true

### Member usage

```java
sb = sb'Hello BoxLang';
result = sb.startsWith( 'Box' );
writeOutput( result );
```

Result: false
