### Calculate bitwise logical NOT

Inverts every bit, using signed two's complement numbers.

```java
writeOutput( bitNot( 0 ) )
```

Result: -1

### NOT of a positive number

```java
writeOutput( bitNot( 255 ) )
```

Result: -256

### NOT twice returns the original number

```java
writeOutput( bitNot( bitNot( 42 ) ) )
```

Result: 42
