### Convert a string to snake_case

```java
result = snakeCase( "helloWorld" );
writeOutput( result );

```

Result: hello_world

### Convert PascalCase to snake_case

```java
result = snakeCase( "MyVariableName" );
writeOutput( result );

```

Result: my_variable_name

### Using the member function

```java
result = "fooBarBaz".snakeCase();
writeOutput( result );

```

Result: foo_bar_baz
