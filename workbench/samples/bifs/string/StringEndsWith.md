### Check if a string ends with a suffix

```java
result = "hello.txt".endsWith( ".txt" );
writeOutput( result );

```

Result: true

### Case-sensitive by default

```java
result = "Hello.TXT".endsWith( ".txt" );
writeOutput( result );

```

Result: false

### Using the member function

```java
result = "myfile.pdf".endsWith( ".pdf" );
writeOutput( result );

```

Result: true
