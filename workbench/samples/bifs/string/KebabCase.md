### Convert a string to kebab-case

```java
result = kebabCase( "helloWorld" );
writeOutput( result );

```

Result: hello-world

### Convert snake_case to kebab-case

```java
result = kebabCase( "my_variable_name" );
writeOutput( result );

```

Result: my-variable-name

### Using the member function

```java
result = "fooBarBaz".kebabCase();
writeOutput( result );

```

Result: foo-bar-baz
