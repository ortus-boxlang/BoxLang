### Convert a string to camelCase

```java
result = camelCase( "hello_world" );
writeOutput( result );

```

Result: helloWorld

### Convert kebab-case to camelCase

```java
result = camelCase( "my-variable-name" );
writeOutput( result );

```

Result: myVariableName

### Using the member function

```java
result = "foo_bar_baz".camelCase();
writeOutput( result );

```

Result: fooBarBaz
