### Check if a string starts with a prefix

```java
result = "hello world".startsWith( "hello" );
writeOutput( result );

```

Result: true

### Case-sensitive by default

```java
result = "Hello World".startsWith( "hello" );
writeOutput( result );

```

Result: false

### Using the member function

```java
result = "https://example.com".startsWith( "https://" );
writeOutput( result );

```

Result: true
