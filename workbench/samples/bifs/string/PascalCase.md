### Convert a string to PascalCase

```java
result = pascalCase( "hello_world" );
writeOutput( result );

```

Result: HelloWorld

### Convert kebab-case to PascalCase

```java
result = pascalCase( "my-variable-name" );
writeOutput( result );

```

Result: MyVariableName

### Using the member function

```java
result = "foo_bar".pascalCase();
writeOutput( result );

```

Result: FooBar
